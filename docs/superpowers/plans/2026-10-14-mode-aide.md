# Mode Aide (aide utilisateur, phase 4) — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un mode Aide activable qui, au survol d'une zone de l'écran (cadre, barre d'espace, zones des 31 vues), l'encadre et affiche à quoi elle sert — en lecture seule.

**Architecture:** Les zones sont marquées sans wrapper : `data-devzone` existants pour le cadre (texte dans `help/shellZones.ts`), nouvel attribut `data-help-zone="<vue>:<zone>"` pour les vues (texte dans le champ `zones` de la fiche de la vue). Un store Zustand porte l'état actif ; un composant global `HelpModeOverlay` (monté dans Layout comme `DevZoneInspector`) intercepte en phase de capture les événements souris/clavier, résout la zone la plus interne ayant un texte (`findHelpZone`), dessine encadré + carte + bandeau. Couverture contrôlée par `help/coverage.test.ts`.

**Tech Stack:** React 18, TypeScript, Zustand, Vitest (projet `web`, jsdom) + Testing Library, Tailwind.

**Spec:** design validé en chat le 2026-10-14 (pas de fichier spec — préférence Thomas) ; spec fonctionnelle SPOK « Aide utilisateur intégrée [help] » `cmv7xld7h00055de22u5fihif` (espace `cmnq9c4aq000k5yz2w1n6e70d`). Résumé du design :
1. Rôle : expliquer les ZONES ; les infobulles (HelpHint) restent pour les commandes.
2. Entrées : bouton « Mode Aide » dans l'encart de chaque « ? » (HelpButton) + raccourci Maj+? (ignoré dans un champ de saisie). Sorties : Échap, bouton Quitter du bandeau, Maj+?.
3. Lecture seule : clics, pointerdown, glisser, menu contextuel, survols (mouseover/out) et touches (sauf Échap, Maj+?) interceptés en capture sur `window` ; seul le bandeau reste cliquable.
4. Survol = zone la plus interne ayant un texte encadrée + carte (titre + 1-3 phrases) ; clic = carte épinglée ; zone sans texte traversée vers son parent.
5. Bandeau fixe : « Mode Aide — survolez une zone pour savoir à quoi elle sert · cliquez pour épingler · Échap pour quitter » + Quitter ; `role="status"`, titre de zone annoncé (`aria-live="polite"`).
6. Ne démarre pas pendant un tour guidé ; au-dessus de l'appli et des modales, sous l'inspecteur de dev.
7. Périmètre : cadre + barre d'espace + 31 vues ; pages/modales plus tard (même attribut, textes dans PAGE_HELP).
8. Contrôle : zone posée ⇔ texte (pas d'orphelin), ≥ 2 zones par vue, zones du cadre ⇔ `data-devzone` réellement posés.

```ts
/*
 * Store du mode Aide (aide utilisateur, phase 4) : actif ou non — état volatil, non persisté (recharger quitte le mode).
 * enter() refuse de démarrer pendant un tour guidé driver.js (popover affiché). Lu par HelpModeOverlay (interception,
 * encadré, bandeau) et HelpButton (bouton « Mode Aide »). Ne pas y mettre l'état de survol : il reste local à l'overlay.
 */
import { create } from 'zustand';

interface HelpModeState {
  active: boolean;
  enter: () => void;
  exit: () => void;
  toggle: () => void;
}

const tourRunning = () => typeof document !== 'undefined' && !!document.querySelector('.driver-popover');

export const useHelpModeStore = create<HelpModeState>((set, get) => ({
  active: false,
  enter: () => { if (!tourRunning()) set({ active: true }); },
  exit: () => set({ active: false }),
  toggle: () => (get().active ? get().exit() : get().enter()),
}));
```

```ts
/*
 * Résolution des zones du mode Aide. Deux marquages, sans wrapper DOM :
 * - cadre et barre d'espace : data-devzone="<nom>" (texte dans SHELL_ZONES) ;
 * - vues (puis pages/modales) : data-help-zone="<fiche>:<zone>" (texte dans VIEW_HELP[fiche].zones, sinon
 *   PAGE_HELP[fiche].zones).
 * findHelpZone remonte du nœud survolé à la zone la plus interne QUI A un texte (une zone sans texte est traversée).
 */
import type { HelpZone } from './types';
import { SHELL_ZONES } from './shellZones';
import { VIEW_HELP } from '../components/views/help';
import { PAGE_HELP } from './pageHelp';

const ZONE_SELECTOR = '[data-help-zone],[data-devzone]';

export function zoneText(id: string): HelpZone | undefined {
  const sep = id.indexOf(':');
  if (sep === -1) return SHELL_ZONES[id];
  const fiche = id.slice(0, sep);
  const zone = id.slice(sep + 1);
  const views = VIEW_HELP as Record<string, { zones?: Record<string, HelpZone> } | undefined>;
  const pages = PAGE_HELP as Record<string, { zones?: Record<string, HelpZone> } | undefined>;
  return views[fiche]?.zones?.[zone] ?? pages[fiche]?.zones?.[zone];
}

export function findHelpZone(target: Element | null): { el: HTMLElement; id: string; zone: HelpZone } | null {
  let el = target?.closest<HTMLElement>(ZONE_SELECTOR) ?? null;
  while (el) {
    const id = el.dataset.helpZone ?? el.dataset.devzone ?? '';
    const zone = zoneText(id);
    if (zone) return { el, id, zone };
    el = el.parentElement?.closest<HTMLElement>(ZONE_SELECTOR) ?? null;
  }
  return null;
}
```

```tsx
/*
 * HelpModeOverlay — mode Aide (aide utilisateur, phase 4). Monté une fois dans Layout (à côté de DevZoneInspector).
 * - Raccourci Maj+? (toujours écouté, ignoré dans input/textarea/select/contenteditable) : bascule le mode.
 * - Mode actif = LECTURE SEULE : écouteurs en capture sur window qui bloquent clics, pointer/mouse down-up, double-clic,
 *   menu contextuel, glisser, survols (mouseover/out : ni infobulle HelpHint ni menu ⋮ au survol) et touches (sauf
 *   Échap = quitter, Maj+? = basculer). Seul le bandeau (data-help-mode-ui) reste cliquable.
 * - Survol : la zone la plus interne ayant un texte (findHelpZone) est encadrée + carte (titre, texte) ; clic = carte
 *   épinglée ; zone retirée du DOM = carte fermée.
 * Textes : jamais ici — SHELL_ZONES (cadre) et fiches des vues (zones). z-index : au-dessus de l'appli, des modales et
 * des tours (10001-10002), sous DevZoneInspector.
 */
import { useEffect, useRef, useState } from 'react';
import { createPortal } from 'react-dom';
import { HelpCircle, X } from 'lucide-react';
import { useHelpModeStore } from '../stores/helpMode';
import { findHelpZone } from './helpZones';
import type { HelpZone } from './types';

interface Hit { el: HTMLElement; zone: HelpZone; rect: DOMRect }

const BLOCKED = ['click', 'dblclick', 'auxclick', 'mousedown', 'mouseup', 'pointerdown', 'pointerup', 'contextmenu', 'dragstart', 'mouseover', 'mouseout', 'submit'] as const;
const CARD_W = 280;

const isTyping = (t: EventTarget | null) => {
  const el = t as HTMLElement | null;
  return !!el && (el.isContentEditable || ['INPUT', 'TEXTAREA', 'SELECT'].includes(el.tagName));
};
const isShiftQuestion = (e: KeyboardEvent) => e.key === '?' && !e.ctrlKey && !e.metaKey && !e.altKey;
const inUi = (t: EventTarget | null) => !!(t as Element | null)?.closest?.('[data-help-mode-ui]');

function cardPosition(r: DOMRect): { top: number; left: number } {
  const vw = window.innerWidth, vh = window.innerHeight;
  let left = r.right + 8;
  if (left + CARD_W > vw - 8) left = r.left - CARD_W - 8;
  let top = r.top;
  if (left < 8) { left = Math.min(Math.max(8, r.left), vw - CARD_W - 8); top = r.bottom + 8; }
  return { top: Math.min(Math.max(48, top), vh - 140), left };
}

export function HelpModeOverlay() {
  const active = useHelpModeStore((s) => s.active);
  const [hover, setHover] = useState<Hit | null>(null);
  const [pinned, setPinned] = useState<Hit | null>(null);
  const pinnedRef = useRef<HTMLElement | null>(null);

  // Raccourci Maj+? : toujours actif
  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      if (isShiftQuestion(e) && !isTyping(e.target)) { e.preventDefault(); e.stopPropagation(); useHelpModeStore.getState().toggle(); }
    };
    window.addEventListener('keydown', onKey, true);
    return () => window.removeEventListener('keydown', onKey, true);
  }, []);

  // Lecture seule + survol, seulement mode actif
  useEffect(() => {
    if (!active) { setHover(null); setPinned(null); pinnedRef.current = null; return; }
    const hit = (t: EventTarget | null): Hit | null => {
      const z = findHelpZone(t as Element | null);
      return z ? { el: z.el, zone: z.zone, rect: z.el.getBoundingClientRect() } : null;
    };
    const block = (e: Event) => {
      if (inUi(e.target)) return;
      e.preventDefault();
      e.stopPropagation();
      if (e.type === 'click') { const h = hit(e.target); pinnedRef.current = h?.el ?? null; setPinned(h); }
    };
    const onMove = (e: PointerEvent) => { if (!inUi(e.target)) setHover(hit(e.target)); };
    const onKey = (e: KeyboardEvent) => {
      if (isShiftQuestion(e)) return; // géré par le raccourci
      if (inUi(e.target) && (e.key === 'Enter' || e.key === ' ' || e.key === 'Tab')) return;
      e.preventDefault();
      e.stopPropagation();
      if (e.key === 'Escape') useHelpModeStore.getState().exit();
    };
    const refresh = () => {
      const el = pinnedRef.current;
      if (el && !el.isConnected) { pinnedRef.current = null; setPinned(null); return; }
      setPinned((p) => (p && p.el.isConnected ? { ...p, rect: p.el.getBoundingClientRect() } : p));
      setHover(null);
    };
    BLOCKED.forEach((t) => window.addEventListener(t, block, true));
    window.addEventListener('pointermove', onMove, true);
    window.addEventListener('keydown', onKey, true);
    window.addEventListener('scroll', refresh, true);
    window.addEventListener('resize', refresh);
    const tick = window.setInterval(refresh, 500); // zone épinglée retirée par un re-rendu
    return () => {
      BLOCKED.forEach((t) => window.removeEventListener(t, block, true));
      window.removeEventListener('pointermove', onMove, true);
      window.removeEventListener('keydown', onKey, true);
      window.removeEventListener('scroll', refresh, true);
      window.removeEventListener('resize', refresh);
      window.clearInterval(tick);
    };
  }, [active]);

  if (!active) return null;
  const shown = pinned ?? hover;
  const pos = shown ? cardPosition(shown.rect) : null;

  return createPortal(
    <>
      <div
        data-help-mode-ui
        role="status"
        className="fixed top-2 left-1/2 -translate-x-1/2 z-[10002] flex items-center gap-3 rounded-lg border border-primary/40 bg-card shadow-lg px-3 py-1.5 text-xs"
      >
        <HelpCircle className="w-4 h-4 text-primary flex-shrink-0" />
        <span><strong>Mode Aide</strong> — survolez une zone pour savoir à quoi elle sert · cliquez pour épingler · Échap pour quitter</span>
```
